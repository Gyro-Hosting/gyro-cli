gyro CLI

gyro: Gyro Hosting hizmetlerini terminalden yönetin.

Kurulum

YöntemKomut
Linux / macOScurl -fsSL https://www.gyrohosting.com/cli/install.sh | sh
Homebrewbrew install gyro-hosting/tap/gyro
Windows (Scoop)scoop bucket add gyro https://github.com/Gyro-Hosting/scoop-bucket
scoop install gyro
Debian / Ubuntusudo apt install ./gyro_<sürüm>_linux_amd64.deb
RHEL / Alma / Rockysudo dnf install ./gyro_<sürüm>_linux_amd64.rpm
Dockerdocker run --rm -e GYRO_TOKEN ghcr.io/gyro-hosting/gyro server list

Tek dosyalık program (Linux, macOS, Windows; amd64, arm64). Sürüm dosyalarının SHA-256 listesi Gyro sürüm anahtarıyla imzalıdır (E96B E963 5E77 A0D9 119A C8C3 A798 6589 A154 B990).

Başlarken

gyro configure                     # API anahtarı: Müşteri paneli → sağ üstteki hesap menüsü → API Kimlik Bilgileri
gyro whoami
gyro plan list --location falkenstein
gyro server create web-1 --plan pro-2-8 --location falkenstein --image ubuntu-24.04 \
     --ssh-key ~/.ssh/id_ed25519.pub --wait
gyro server ssh web-1

Sipariş komutu önce API'den fiyat teklifini gösterir, onayınızı ister ve bakiyeden öder. --wait sunucu çalışana kadar bekler.

Örnek oturum

$ gyro server create web-1 --plan standart-1-1 --location falkenstein --image debian-12 --ssh-key laptop --wait

Profiller ve kimlik

  • gyro configure [--profile ad] anahtarı doğrular ve ~/.config/gyro/config.toml dosyasına (izin 0600) yazar; --keyring işletim sistemi anahtar zincirini kullanır.
  • Betikler: echo "$ANAHTAR" | gyro configure --token-stdin --profile ci ya da yalnız GYRO_TOKEN.
  • Öncelik: bayrak > ortam (GYRO_TOKEN, GYRO_PROFILE, GYRO_API_URL, GYRO_OUTPUT, GYRO_LANG) > profil.
  • gyro context etkin profili ve anahtar yetkilerini gösterir; gyro context use ad varsayılanı değiştirir.

Çıktı ve betikler

  • -o table|json|yaml|text, --query (JMESPath), -q yalnız kimlikler, --no-header, --wide.
  • Renkler yalnız terminalde; NO_COLOR kapatır. Dil yerel ayardan ya da --lang tr|en.
  • Ad ya da kimlik: gyro server get web-1 ve gyro server get 47485 aynıdır.
  • Kabuk tamamlama: gyro completion bash|zsh|fish|powershell (sunucu ve anahtar adları API'den tamamlanır).

Güvenlik: onay, deneme, idempotency

  • Para harcayan ve geri alınamayan işlemler onay sorar; betiklerde --yes. Terminal yoksa ve --yes verilmemişse komut çalışmaz (çıkış kodu 7).
  • --dry-run fiyat teklifini (destekleyen uçlarda) ya da gönderilecek isteği gösterir; hiçbir şey değişmez.
  • Para işlemlerine otomatik Idempotency-Key eklenir: tekrar çalıştırmak ikinci sipariş vermez.
  • 429/5xx yanıtlarında güvenli istekler artan beklemeyle tekrarlanır. Hatalar API kodu, HTTP durumu ve istek numarasıyla yazılır.

Tüm ürünler

Mail, S3, izleme, lisans, VDS, fiziksel sunucu ve uygulama hizmetleri aynı köprüden yönetilir. Araçlar ve eylemler hizmetten okunur, yeni özellikler CLI güncellemesi beklemeden çalışır:

gyro mail list
gyro mail tools example.com                       # araçlar, eylemler, onay/sır politikası
gyro mail mailbox create example.com --set local_part=info --set password=@-
gyro s3 bucket list depom
gyro license status 48001
gyro service tool run 48001 <araç> <eylem> --set alan=değer
