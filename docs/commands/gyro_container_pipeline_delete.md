## gyro container pipeline delete

Delete a pipeline

### Synopsis

Delete a pipeline

Stops its running runs and deletes its history, webhook secret, token and build secrets. Images stay in the registry. Needs `"confirm": true`.

API: DELETE /cloud/containers/{id}/pipelines/{pipeline} (operationId pipeline_delete, scope services_write)

```
gyro container pipeline delete <ID> <PIPELINE> [flags]
```
