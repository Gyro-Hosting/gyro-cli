## gyro container schedule delete

Delete a scheduled job

### Synopsis

Delete a scheduled job

Deletes the schedule and its stored HTTP headers / body. A run in progress finishes; outputs of past runs stay in the job list. Send `{"confirm": true}`.

API: DELETE /cloud/containers/{id}/schedules/{sched} (operationId deleteContainerSchedule, scope services_write)

```
gyro container schedule delete <ID> <SCHED> [flags]
```
