## gyro security-group delete

Delete a security group

### Synopsis

Delete a security group

Only a group that is attached to no server (422 err_sg_attached).

API: DELETE /cloud/security-groups/{sg} (operationId deleteSecurityGroup, scope cloud_write)

```
gyro security-group delete <SG> [flags]
```
