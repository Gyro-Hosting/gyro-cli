## gyro dns zone delete

Delete a zone

### Synopsis

Delete a zone

Removes the zone and its health checks from our name servers at once. Needs `"confirm": true`.

API: DELETE /cloud/dns/{id}/zones/{zone} (operationId typed_delete_dns__id__zones__zone, scope services_write)

```
gyro dns zone delete <ID> <ZONE> [flags]
```
