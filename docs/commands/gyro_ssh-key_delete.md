## gyro ssh-key delete

Delete an SSH key

### Synopsis

Delete an SSH key

Removes the key from your account. Servers that already have it keep it.

API: DELETE /cloud/ssh-keys/{id} (operationId deleteSshKey, scope cloud_write)

```
gyro ssh-key delete <ID> [flags]
```
