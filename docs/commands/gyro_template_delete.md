## gyro template delete

Delete a template

### Synopsis

Delete a template

Permanent. Servers created from it are not affected; the charge stops from the next hour.

API: DELETE /cloud/templates/{id} (operationId deleteTemplate, scope cloud_write)

```
gyro template delete <ID> [flags]
```
