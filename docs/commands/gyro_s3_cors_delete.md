## gyro s3 cors delete

Remove every CORS rule of a bucket

### Synopsis

Remove every CORS rule of a bucket

Browsers can no longer read the bucket cross-origin. Needs `"confirm": true`.

API: DELETE /cloud/storage/{id}/buckets/{bucket}/cors (operationId typed_delete_storage__id__buckets__bucket__cors, scope services_write)

```
gyro s3 cors delete <ID> <BUCKET> [flags]
```
