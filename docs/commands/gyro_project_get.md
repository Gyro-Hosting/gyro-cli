## gyro project get

Get a project with its service ids

### Synopsis

Get a project with its service ids

Another account's project answers 404 `project_not_found`.

API: GET /cloud/projects/{id} (operationId getProject, scope services_read)

```
gyro project get <ID> [flags]
```
