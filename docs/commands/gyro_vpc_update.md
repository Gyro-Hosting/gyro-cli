## gyro vpc update

Rename a private network

### Synopsis

Rename a private network

Only the name changes (the range never changes).

API: PATCH /cloud/vpcs/{vpc_id} (operationId updateVpc, scope cloud_write)

```
gyro vpc update <VPC-ID> [flags]
```
