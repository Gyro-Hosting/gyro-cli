## gyro backup-space get

Get a backup space

### Synopsis

Get a backup space

Service row plus `backup_space`: SFTP host, port, user, writable path, size, usage, bound server, allowed IPs and state. The password is not included (see /credentials).

API: GET /cloud/backup-spaces/{id} (operationId getBackupSpace, scope services_read)

```
gyro backup-space get <ID> [flags]
```
