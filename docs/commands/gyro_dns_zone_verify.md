## gyro dns zone verify

Verify ownership now

### Synopsis

Verify ownership now

Checks delegation / TXT now (the system also re-checks automatically for 14 days).

API: POST /cloud/dns/{id}/zones/{zone}/verify (operationId typed_post_dns__id__zones__zone__verify, scope services_write)

```
gyro dns zone verify <ID> <ZONE> [flags]
```
