## gyro s3 alerts delete

Remove the fill alert of a bucket

### Synopsis

Remove the fill alert of a bucket

Turns the alert off. Bucket data is not touched, so no `confirm` is needed.

API: DELETE /cloud/storage/{id}/buckets/{bucket}/alert (operationId deleteStorageBucketAlert, scope services_write)

```
gyro s3 alerts delete <ID> <BUCKET> [flags]
```
