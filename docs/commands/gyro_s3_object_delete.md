## gyro s3 object delete

Delete objects

### Synopsis

Delete objects

Deletes up to 1000 keys in one call. Needs `"confirm": true`.

API: POST /cloud/storage/{id}/buckets/{bucket}/objects/delete (operationId typed_post_storage__id__buckets__bucket__objects_delete, scope services_write)

```
gyro s3 object delete <ID> <BUCKET> [flags]
```
