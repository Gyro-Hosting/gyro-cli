## gyro s3 events rotate-secret

İmza gizli anahtarını yenile

### Synopsis

İmza gizli anahtarını yenile

Yeni gizli anahtar oluşturur (bir kez döner); sonraki olaydan itibaren teslimler onunla imzalanır. `{"confirm": true}` gönderin.

API: POST /cloud/storage/{id}/events/{event}/rotate-secret (operationId rotateStorageEventWebhookSecret, scope services_write)

```
gyro s3 events rotate-secret <ID> <EVENT> [flags]
```
