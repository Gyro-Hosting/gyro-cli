## gyro server disk resize

Ek diski büyüt

### Synopsis

Ek diski büyüt

Diski `size_gb` boyutuna büyütür (küçültmez; snapshot varken olmaz). Sonra sunucu içinde bölümü / dosya sistemini genişletin.

API: PUT /cloud/servers/{id}/disks/{disk} (operationId resizeServerDisk, scope cloud_write)

```
gyro server disk resize <ID> <DISK> [flags]
```
