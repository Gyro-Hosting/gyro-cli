## gyro backup-space get

Yedekleme alanı ayrıntısı

### Synopsis

Yedekleme alanı ayrıntısı

Hizmet satırı ve `backup_space`: SFTP adresi, port, kullanıcı, yazılabilir dizin, boyut, kullanım, bağlı sunucu, izinli IP'ler ve durum. Parola yoktur (/credentials).

API: GET /cloud/backup-spaces/{id} (operationId getBackupSpace, scope services_read)

```
gyro backup-space get <ID> [flags]
```
